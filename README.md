# Job Portal

A simple full-stack job portal where users can search for jobs and apply for them. Recruiters can also post jobs and manage applications.

## Features

* User registration and login
* Search and view jobs
* Apply for jobs
* Recruiter can post jobs
* Recruiter can manage job postings
* User and recruiter profiles
* Authentication and protected routes

## Tech Stack

**Frontend**

* React.js
* JavaScript
* HTML
* CSS

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

## Project Structure

## How to Run

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Create a `.env` file inside the `backend` folder and add your required environment variables.
